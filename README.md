### About

I run **Divox**, a one-person studio where I design and build web products for freelancers, SMBs and startups — from simple websites to full SaaS platforms.

I focus on shipping real things: clean code, solid architecture, interfaces that people actually want to use.

- Currently building and maintaining production apps (React, Next.js, Node.js)
- Based in Toulouse, working remotely across France and Europe
- Open to freelance projects and interesting collaborations
